# Lesson 13 sentence audio pilot

The Chinese translation view contains 21 inline Japanese sentence controls in the
existing five paragraphs. A click plays that sentence from the original track;
another click restarts it. The active sentence is highlighted. Enter and Space
work when a sentence has keyboard focus. Paragraph controls retain stop/replay
behavior. Switching views, hiding the page or starting the full track stops the
clip. Existing ruby nodes are retained, including the second 月極 override in
paragraph 5. The existing font controls also apply to this translation view.

## Alignment and limits

Source: https://ttrw.jp/static/sound/sound202406141718352260.mp3

The 252.704-second original MP3 was already available locally. Sentence ranges
were matched to its existing local word timestamp transcript, then refined using
FFmpeg `silencedetect=noise=-38dB:d=0.3` on the actual recording. Internal starts
are approximately 250ms before the corresponding detected speech onset; internal
ends are approximately 250ms into the following silence. Existing outer paragraph
boundaries are retained. Ranges are explicitly bound to the complete displayed
sentence text; they are not estimated from character counts or equal divisions.
The quoted question in paragraph 1 remains part of its complete reporting
sentence; paragraph 2's 「月極」——。 is a separate spoken sentence.

MP3 SHA-256: `adbab3721a77f288485b0d2e0e243558929251784fd446636e9dddd2b6cc2a4d`.
Cached word-timestamp JSON SHA-256:
`f1ef00bfdf3849a3898d8ee76333316b39b2ca08c56de3514b85908bd2fb76d0`.

These boundaries have **not been audibly verified**. Native-browser tests decode
and play the actual MP3, verifying seeking and automatic stop behavior. They do
not establish a human listening judgment or sample-perfect accuracy.

The cached transcript was generated by the existing local
`reading-audio-transcribe.py`: faster-whisper small, Japanese, CPU int8,
beam size 5, word timestamps enabled, VAD disabled, with only the reading title
as a prompt. Its source JSON records the same URL and duration as this MP3.
All 42 selected boundary positions were independently checked against measured
silence in that exact file. There are no ambiguous sentence-to-range matches.

A further local check transcribed each of the 21 cropped ranges independently
using the original compatible Python 3.11 setup and cached small model. Every
clip's recognized opening and ending matches the intended sentence, with normal
recognition errors (for example 月極 as 結局 and 和英辞典 as ワイエージ店).
Those lexical errors do not change which sentence a range contains. No adjacent
sentence text appeared in the cropped transcripts. The earlier Python 3.10
attempt could not import PyAV under Windows Application Control; no control
settings were changed. The original Python 3.11 installation worked normally.
No model, private data or audio was sent to an external processor.
Human listening remains an additional quality check for quiet phonetic tails.

The original external audio remains excluded from the offline package. Sentence
playback needs that source available through the network or browser cache; the
site does not promise offline audio. No third-party audio is checked in or
redistributed. iPhone Safari has not been directly tested.

## Validation

Local Microsoft Edge / Chromium, isolated profiles, original MP3 routed from the
existing local file for repeatable tests:

- `node scripts/test-reading-sentence-audio.mjs`: all 21 sentence starts/ends,
  natural completion, same-sentence replay, 60 rapid switches, active highlight,
  paragraph/sentence/full-track switching, original/translation/vocabulary views,
  keyboard controls, retained ruby and font controls, navigation/pagehide,
  simulated visibility cleanup, audio-load failure and successful retry.
  Responsive widths: 320, 390, 768 and 1440px. Long sentences wrap across lines.
- `node scripts/test-reading-paragraph-audio.mjs`: 45 original-audio paragraph
  ranges across lessons 13–20 seek and stop correctly.
- `node scripts/test-reading-translations.mjs`: bilingual text, furigana,
  paragraph controls and responsive regressions across lessons 13–20. Its media
  mock now emits `seeked`, matching the native media lifecycle.
- `node scripts/test-lesson13-reading.mjs`: textbook reading, saved drafts,
  questions and exam checks at desktop, iPad and mobile sizes.
- `node scripts/test-lesson13-additions.mjs`: sources, preserved IDs, hints,
  drafts, shortcuts, furigana and responsive teacher additions.
- `node scripts/generate-offline-manifest.mjs`, then `node scripts/test-pwa.mjs`:
  73 pages, 235 same-origin resources. External audio remains excluded.

Set `JPY5_BROWSER_CHANNEL=msedge` on Windows. For native media tests set
`JPY5_READING_AUDIO_DIR` to a local directory containing existing official tracks
named `13.mp3` through `20.mp3`. The new pilot test requires `13.mp3`. Browser
tests require Playwright; it remains a local test dependency, with no production
package or build dependency added.

Review evidence is kept locally under `tmp/sentence-pilot/` (viewport captures,
an active-sentence capture, per-sentence results, silence audit and local ASR report). These are not site assets.
This pilot is limited to lesson 13; lessons 14–20 retain paragraph playback.
