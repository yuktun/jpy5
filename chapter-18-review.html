第18課（1）読む・書く

I

□の中から（　）に合う言葉を選んで、書いてください。必要があれば形を変えてください。また、漢字の言葉にはひらがなで読み方も書いてください。

滑鼠移到詞語、手機輕觸或鍵盤聚焦，可看本題的中文意思與用法。

  1. 疲れていたので、頭の（　　　　　　）から、足の先さきまで全身マッサージしてもらった。
  2. もうすぐお客さんが来るから、机の上に（　　　　　　）本とか雑誌とかを片付けなきゃ。
  3. 仕事で失敗することなんて（　　　　　　）あることだから、くよくよしないで次がんばればいい。
  4. 勉強したことがないので、タイ語の文字は見てもどんな意味か（　　　　　　）もつかない。
  5. このナイフの刃はとても（　　　　　　）ので、使うときは十分気をつけてください。
  6. 彼女の趣味は映画を見ることだが、多くの人に人気がある映画よりも、どちらかというとあまり知られていない（　　　　　　）な映画のほうが好きだという。
  7. 彼とは大学を卒業して以来、全く連絡をとっていないので、彼の今の仕事について知る（　　　　　　）もない。

II

1）次の意味にいちばん近いものを選んでください。

例）頭に浮かぶ → ア　想像される。

① 手に入れる② 目をとめる③ 手にとる
ア　想像される。イ　注意して見る。ウ　持つ。エ　自分のものにする。

2）下の文の１～３に合うものを上の①～③から選んで書いてください。必要なら形を変えてください。番号だけ書かないで、きちんと言葉を書いてください。

  1. 本屋で以前からほしかった本を見つけたので、（　　　　　　　　　）中を見たが、買わなかった。
  2. 先週レストランに行ったら、チョウ・ユンファ（周潤發）が食事をしていたので、多くの人が彼に（　　　　　　　　　）。
  3. 昨日やっと新しいiPhoneを（　　　　　　　　　）が、時間がなくて、まだあまり使っていない。

1）① エ（自分のものにする）　② イ（注意して見る）　③ ウ（持つ）

2）1. 手にとって　2. 目をとめた　3. 手に入れた

III

教科書の「読もう」を読んで以下の問題に答えてください。

  1. 渡辺昇わたなべのぼるという人の説明で合っているものを選んで、○をつけてください。（答えは１つ以上あるかもしれません。）
    1. 渡辺昇は中学生だ。
    2. 渡辺昇は鉛筆削りのマニアックなコレクターだ。
    3. 渡辺昇のテーブルの上はきれいじゃない。
    4. 渡辺昇は「僕」の家に修理に来た。
    5. 渡辺昇はかばんにいつも古い鉛筆削りを入れて、持ち歩いている。
  2. 「僕」が昔から持っていた鉛筆削りの説明として合っているものを選んで、○をつけてください。（答えは１つ以上あるかもしれません）
    1. 最新式だ。
    2. 薄汚い。
    3. かなり錆びている。
    4. いつも台所に置いてある。
    5. 鉄腕アトムのシールがついている。
  3. 12行目「渡辺昇」が「ねえ、ご主人、その鉛筆削りいいですねえ」と言ったとき、「僕」が「これ？」とびっくりしたのはどうしてですか。
    から。

1）B・D。渡辺昇は収集家で、水道関係の修理屋として来ました。散らかった机は「僕」の机です。交換用に持ち歩くのは新品です。

2）B・C・E。台所に置いたのは気分転換のためにそこで仕事をしていたその日で、いつもではありません。

建議答案：其他符合文意、文法正確而自然的表達也可以。自分にとっては、二十年以上使っているごく普通の古くて汚い鉛筆削りで、特に価値があるとは思っていなかったからです。

第3題是理由說明，另設「建議答案」。第1、2題依本文第2、3、5、8段核對；第3題依第5段。

IV

「渡辺昇」は「僕」の古い鉛筆削りに価値を感じていましたが、「僕」は特に興味がありませんでした。あなたの「他の人は価値を感じないかもしれないけど、私は価値を感じるもの」について、一つ書いてください。それから、その理由について２行以上３行以内で書いてください。

私が価値を感じるのは、です。



建議答案：其他符合文意、文法正確而自然的表達也可以。私が価値を感じるのは、子どものころに使っていた古い鉛筆です。
短くなってもう書きにくいですが、祖父が入学祝いにくれた大切なものです。
これを見ると、祖父と一緒に勉強した楽しい時間を思い出すので、捨てられません。

起首句之後的理由分成2個書寫行，符合原題理由2至3行；手機顯示會自然折行。

第18課（2）話す・聞く

I

会話を完成してください。

  1. Aさんがほめてくれました。「だって」（話す・聞く７）という表現を使って、Aさんをほめ返してください。
    A：「Bさんの新しいメガネ、すごくいいね。」
    B：Aさんだって、。
  2. Aさんに皮肉ひにく（＝irony／諷刺）を言われました。「だって」（話す・聞く７）という表現を使って、Aさんに皮肉を言い返してください。
    A：「Bさん、また遅刻。いつも10分以上遅れてくるよね。」
    B：Aさんだって、。
  3. 「こそ」（話す・聞く８）という表現を使って、今年の目標を言ってください。
    A：来年は、どんな１年にしたい？
    B：来年こそ。
  4. お母さんと子どもが話しています。「だって」（話す・聞く５）という表現を使って言いい訳わけ（＝excuse）を言ってください。
    母：甘いもの、食べすぎよ。
    子：だって、。
建議答案：其他符合文意、文法正確而自然的表達也可以。
  1. Aさんだって、そのネクタイ、すごく似合っているよ。
  2. Aさんだって、この前30分も遅れて来たじゃない。
  3. 来年こそ日本語能力試験のN2に合格したいです。
  4. だって、おいしいんだもん。

第3題的指示寫「今年」，但原對話A、B都寫「来年」；保留原題，範例依對話回答明年目標。前兩題「Nだって」是「N也……」，第4題句首「だって」用來辯解。

II

駅でミラーさんとマリアさんが話しています。正しいほうに○を書いてください。

(電車を降りて、改札を出るとき)ミラー：ごめん、マリアさんちょっと待って。切符が見つからないんだ。えーと、どこにしまったっけ…。…あ、こんなところに（ ある ・ あった ）。マリア：ミラーさんって、よく物をなくしたり忘れたりするよね…。家のかぎとか、今持ってる？ミラー：家のかぎは（ ある ・ あった ）よ！そんな大切なものはなくさないよ！マリア：でも去年の旅行のとき、パスポートなくして大変だったでしょう。ミラー：なくしてないよ！ホテルのベッドの上に（ ある ・ あった ）んだから！マリア：「パスポートが（ ない ・ なかった ）！」って大声で言いながら探してたでしょう？ミラー：…そうだったっけ……？
  1. あった（今、切符を見つけたときの発見の「あった」）
  2. ある（家のかぎは今持っている）
  3. あった（去年、ホテルのベッドの上にあった）
  4. ない（探していた当時の「ない！」という発言をそのまま引用）

III

会話で勉強した表現を使って、次の会話を完成してください。（　）の中の言葉が表現の最初の文字もじです。それに続けて書いてください。

太郎（男）と花子（女）は恋人です。お互いに相手のすることが気に入らないので、不満や文句を言ってけんかしますが、最後に謝って、仲直りします。

＜場面１＞太郎はデートのとき、いつも携帯電話ばかり見ています。今日もデート中に携帯を見て、ゲームをしています。花子もときどき携帯でインターネットを見ます。花子：また、ケータイ見てる！（ し　　　　　　）ケータイ見ているよね。いっしょにいるんだから、ケータイばかりみないでよ。太郎：あ、ごめん。ごめん。このゲームすごくおもしろくて…。花子もやってみない？花子：（ だ　　　　　　）私とデートしているのに、ケータイでゲームするほうが楽しいの？そんなに好きなら、ケータイと結婚すれば。太郎：そんなに（ 言　　　　　　）いいじゃないか。花子だって、ケータイでインターネット、見ることあるだろう？（ お　　　　　　）なんじゃない？花子もそんなにインターネットみたいなら、俺とデートなんかしないで、ずっと家でパソコンしていればいいだろ。＜場面２＞お互いに言い過ぎたことに気がついて、謝ってください。そしてけんかを終わらせてください。花子：（ ご　　　　　　）、ちょっと（ 言　　　　　　）みたい。太郎：僕のほうこそ、ごめん。いっしょにいるのに、ケータイばかり見てる俺が悪いよね。花子：ううん、（ 私　　　　　　）、ごめん。太郎：あ、見たいって言ってた映画、あと20分で始まるよ。早く行こう。花子：そうね。

場面１（空格內的完整表現，包含題目提示的首字）：

  1. しょっちゅう
  2. だいたい
  3. 言わなくたって
  4. お互いさま

場面２：

  1. ごめん
  2. 言い過ぎた
  3. 私こそ

完整句：「ごめん、ちょっと言い過ぎたみたい。」「ううん、私こそ、ごめん。」

答案列出包含提示首字的完整表現，填寫時只須在原稿的首字後接續。「みたい」「いいじゃないか」等已印出的部分不重複填。

第18課（3）文法・練習

I

□の中から正しいものを選んで、文を完成してください。必要なら形を変えてください。それぞれのことばは１回しか使えません。

滑鼠移到詞語、手機輕觸或鍵盤聚焦，可看本題的中文意思與用法。

  1. 来年発売されるiPadは以前の物（　　　　　　　　　）画面がさらに見やすくなったという。
  2. こんな難しい問題は何度やってみた（　　　　　　　　　）、わかるはずがない。
  3. お金というものはそんな簡単にもらえる（　　　　　　　　　）。
  4. わたしは好きな水泳選手がいる。彼は次のオリンピックで、きっと金メダルを取る（　　　　　　　　　）。
  5. A：わたしの英語の先生、何ヶ国なんかこく語も話せるんだよ。日本語（①　　　　　　）韓国語（②　　　　　　）できるんだよ。すごいでしょ？
    B：へえ、すごい！わたしなんか日本語しか話せないのに…。
    ※①と②は同じ言葉を使います。
  1. に比べて
  2. ところで
  3. ものではない
  4. に違いない
  5. ① だって　② だって

II

文を完成させてください。

  1. キッチンがめちゃくちゃだ。から、犯人はうちの猫に違いない。
  2. はに比べて。
  3. 風邪を引いているときはものだ。
  4. たところで、はをやめないと思う。
建議答案：其他符合文意、文法正確而自然的表達也可以。
  1. キッチンがめちゃくちゃだ。床に猫の足跡が残っているから、犯人はうちの猫に違いない。
  2. 今年の冬は去年の冬に比べて暖かい。
  3. 風邪を引いているときはゆっくり休むものだ。
  4. 何度注意したところで、彼はたばこをやめないと思う。

第4題原稿的「たところで」已印出，因此第一格填「何度注意し」，完整句為「何度注意したところで」。

III

「こそ」を使って、ある言葉を指示のとおりに強調する文を書いてください。

例）心配だから、何度も電話をかけている。（「心配だから」を強調）
→ 心配だからこそ、何度も電話をかけている。

  1. 今年はN2の試験に合格できるように勉強します。（「今年」を強調）
    →
  2. 彼はこの会社に必要な人材です。（「彼」を強調）
    →
  3. スポーツもゲームも、自分でやればおもしろさがわかる。（「自分でやる」を強調）
    →
  1. 今年こそN2の試験に合格できるように勉強します。
  2. 彼こそこの会社に必要な人材です。
  3. スポーツもゲームも、自分でやってこそおもしろさがわかる。

第3題強調成立條件，用「Vてこそ」；原句的條件「やれば」改為「やってこそ」。

V

□の中から正しいものを選んで、文を完成してください。また、漢字の言葉にはひらがなで読み方も書いてください。

滑鼠移到詞語、手機輕觸或鍵盤聚焦，可看本題的中文意思與用法。

  1. 日本に来てもう３年も経つのに、（　　　　　　）日本の習慣に慣れていない。
  2. まだ引っ越してきたばかりなので、部屋が（　　　　　　）している。
  3. A：すみません。最近、体調も悪いし…。あ、それに、日本語のクラスの宿題もたくさんあるし…。
    B：そう。わかった。（　　　　　　）明日のカラオケには来られないってことだね。
  4. 今回の試験は（　　　　　　）簡単で、基本的きほんてきな問題しかなかったので、合格するに違いない。
  5. 私はとなりに座っている人のケータイ画面を（　　　　　　）横目で見ていた。
  6. 彼は仕事について不満を言っていたので、（　　　　　　）来年あたり仕事をやめるだろう。
  1. いまだに
  2. 雑然と（ざつぜんと）
  3. 要するに（ようするに）
  4. ごく
  5. ちらちらと
  6. おそらく
