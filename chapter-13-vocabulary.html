老師補充

時間関係の副詞

老師講義中的四個時間副詞、例文與練習。本補充不計入 159 詞或詞彙進度。

もう

完了後
  • リンさんはもう国へ帰った。
  • 妹も弟も、もう高校を卒業した。

すでに

完了後・長い時間

「もう」とほとんど同じ（書き言葉）。しかし、「終わってから長時間が経っている状況」に使う場合が多い。

  • 問題点はすでに解決した。
  • 会議で使う書類はすでに準備ができている。

とっくに

完了後・すごく長い時間（主観）

「話している時間よりずっと前に発生している」という場合。

  • 会場についたときには、会はとっくに始まっていた。
  • 父：テレビを見ていないで、早く宿題をしなさい。
    息子：宿題なんかとっくにやったよ。

かつて

過去

「昔の時間」を表している。

  • この町はかつて小さい村だった。
  • わたしはかつてイギリスにいたころ、よく博物館に行った。
學習補充（非老師原文）

語感比較・中文解說

這四個副詞都和時間有關，但重點不只是中文意思，而是事情發生的時間，以及說話者對時間距離的感覺（語感）。

副詞中文理解語感
もう已經最普通、最常用的「已經」，只表示事情已經發生或完成，不特別強調多久以前。
すでに已經、早已和「もう」很接近，但較常見於書面或正式表達；常有「事情較早之前已經完成／成立」的感覺。
とっくに老早就、一早就強調從說話者角度看，事情在很早之前已經發生或完成；主觀時間感最強。
かつて曾經、以前表示過去曾有某種狀態或經歷；重點不是「已經完成」，而是「以前曾經」。

もう

最普通的「已經」。只要想表達「事情已經做了／發生了」，通常可以先想到「もう」。

もう食べました。→ 已經吃了。

すでに

可以理解成「早已」。語氣比「もう」較正式、較書面，而且常用於事情在較早之前已經完成或成立。

問題点はすでに解決した。→ 問題早已解決。

もう終わりました。
→ 普通會話的「已經完成了」

すでに終了しています。
→ 較正式／書面的「早已完成」

とっくに

意思接近「老早就……了」。重點是說話者覺得事情比現在早很多已經發生。常帶有「你現在才問？我一早做了」的語感。

宿題なんかとっくにやったよ。→ 功課我老早就做完了。

会議はすでに始まっています。
→ 客觀地說：會議已經開始。

会議はとっくに始まっているよ。
→ 帶主觀語感：會議老早就開始了。

かつて

意思是「曾經／以前」。它和前面三個最大的不同，是它不是強調「已經完成」，而是在說過去曾經存在的狀態或經歷。

この町はかつて小さい村だった。→ 這個城鎮以前曾經是一條小村。
香港はかつてイギリスの統治下にあった。→ 香港曾經處於英國管治之下。

快速記法

  • もう = 已經
  • すでに = 早已（較正式／書面）
  • とっくに = 老早就（主觀強調）
  • かつて = 曾經

判斷方法

  • 只是想說「已經做了」 → もう
  • 正式／書面地說「早已完成」 → すでに
  • 想強調「一早就做了啦」 → とっくに
  • 說以前曾經有某種狀態／經歷 → かつて
かつて ← 過去某段時期とっくに ← 很早之前已完成すでに ← 較早之前已完成もう ← 已經完成現在

※ 這只是幫助理解的概念圖，不代表四個副詞有固定的時間長度。特別是「すでに」和「とっくに」的差別，也包括正式程度和說話者的主觀語感。

問題１．適当なものを選んでください。

  1. A：あれ、Bさん、（ もう ・ すでに ）昼ごはんを食べたの？
    B：うん、さっき食べたよ。
  2. 部長：工場の計画は進んでいますか。
    社員：はい、現場の調査も（ すでに ・ かつて ）終わっています。
  3. わたしは（ とっくに ・ かつて ）東京に住んでいたことがある。
  4. （大学で）
    A：来週までの木村先生のレポート、早く出したほうがいいよ。
    B：あ、それなら先週（ とっくに ・ かつて ）出したよ。
  1. もう
  2. すでに
  3. かつて
  4. とっくに

問題２．副詞の使い方に注意して、文を完成させてください。

  1. 昨日買ったワインを飲もうと、家に帰って冷蔵庫を開けたら、ワインは家族の誰かにすでに半分（　　　　　　　　　　　）。
  2. A：ねえ、新しい彼氏って、どんな人？
    B：え？とっくに（　　　　　　　　　　　）。
  3. 香港はかつて（　　　　　　　　　　　）。
